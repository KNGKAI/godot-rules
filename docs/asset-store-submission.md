# Godot Asset Library submission notes

- Addon: Godot Rule Engine
- Version: 0.1.0
- Godot compatibility: 4.7.1 and later 4.7 patch releases
- License: MIT
- Install path: `addons/rule_engine/`

## AI-use disclosure

Generative AI tools assisted with planning, implementation, tests, and
documentation. The resulting source code and package contents were reviewed
and verified by the maintainer. No generated media assets are included.

## Package boundary

The distributable addon includes its own README and full license. Repository
tests, examples, planning/research documents, and development tooling are not
part of the Asset Library package. The editor export plugin excludes only the
addon's `editor/` directory from exported games; runtime, resources, and
project-authored rule data remain available.
