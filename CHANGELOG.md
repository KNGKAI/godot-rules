# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-09-01

- Added Resource-authored reactive and queryable rules.
- Added deterministic condition evaluation and two-phase queued dispatch.
- Added payload, fact-provider, and per-engine blackboard namespaces.
- Added built-in compare, exists, boolean-composition, event, and blackboard types.
- Added native Inspector integration, extension discovery, and validation.
- Added an optional `Rules` autoload and runtime-safe export filtering.
- Added a runnable progression/unlock example and headless verification tools.
